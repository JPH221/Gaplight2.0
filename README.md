# 隙光 GapLight2.1

面向大学新生的自适应课隙规划工具 —— 本地运行的 Streamlit 网页应用。

解决三个真实问题：

1. 两项固定安排之间 15~120 分钟的零散课隙，不知道适合做什么；
2. 临时会议、社团活动、调课、任务延误出现后，原计划整体失效；
3. 普通日程工具把空闲排得太满，忽略移动、疲劳和主动休息。

## 运行方式

需要 Python 3.9 或以上（推荐 3.11~3.13）。

```bash
pip install -r requirements.txt
streamlit run app.py
```

浏览器打开终端里给出的地址（默认 <http://gaplight.streamlit.app/）即可使用。>  
首次运行如出现输入 Email 的提示，直接回车跳过即可。  

## 功能对照

| # | 功能                                               | 位置            |
| - | ------------------------------------------------ | ------------- |
| 1 | 课表手动录入（一学期一次，支持单双周、上课地点）＋ 临时活动单独添加               | 「课表与活动」       |
| 2 | 任务添加＋4 类模板自动拆分（每步 15~25 分钟一个番茄，可改名/改时长/删除，附假设声明） | 「任务管理」        |
| 3 | 每日编排：选日子（今天/明天）＋精力状态 → 硬约束＋四因素打分生成计划，每项附具体理由     | 「今日计划」        |
| 4 | 局部重排：冲突/未完成/跳过/超时/临近截止/改精力/主动触发，只动当前之后且未锁定项      | 「今日计划」        |
| 5 | 用户决策与记录：变更说明＋一键确认/拒绝；自动记录全部操作                    | 「今日计划」「记录与导出」 |
| 6 | 每日舒缓文案（可更换/关闭，随计划保存）＋ 实验原始记录导出                   | 「今日计划」「记录与导出」 |

## v2 生活节律（内置规则，无需任何外部 AI）

- **单双周课表**：以"学期第一周周一"为基准自动判断单双周，一学期只录一次；
- **三餐午休**：早餐/午餐/午休/晚餐作为每日固定安排（晚餐按"傍晚是否有课"自动选时段），自然切出课隙；
- **番茄节奏**：连续学习约 25 分钟自动插入 5 分钟休息，每 4 个番茄后 15 分钟大休息；
- **校园跑**：第 2~16 周累计 ≥30 次，正常每周 2 次、落后进度自动加密为 3 次，安排在当天最后一项（跑完洗澡）；
- **规划窗口 8:00~21:30**，任何精力状态都不排满（留白上限 低50%/中65%/高75%），计划之间保留动态缓冲。

## 目录结构

```
gaplight/
├── app.py                # Streamlit 界面入口（5 个页面）
├── gaplight/
│   ├── models.py         # 数据模型（课程/活动/任务/步骤/计划）
│   ├── store.py          # JSON 持久化 + JSONL 实验日志
│   ├── splitter.py       # 4 类任务拆分模板（番茄长度）
│   ├── scheduler.py      # 课隙计算 + 硬约束 + 四因素打分 + 番茄/校园跑 + 重排
│   ├── copytext.py       # 每日舒缓文案库
│   └── exportlog.py      # 记录导出 JSONL/CSV
├── data/                 # 运行后自动生成：数据与日志
├── docs/指标定义附录.md   # 6 项实验指标的冻结定义与公式
├── test_flow.py          # 逻辑冒烟测试（59 项）
└── requirements.txt
```

## 说明

- 晚上和周末不作主要规划对象，仅在临近截止且白天课隙不足时提示兜底风险。
- 无合适任务时宁可留白并说明原因；任何精力状态都不排满（留白上限可调）。
- 指标人工计算，见 `docs/指标定义附录.md`。
